# Plan reader

The approved concepts establish a typography-first Markdown document with inline values that reveal their controls only when selected. Reading and adjustment are one flow.

- `markdown-plan-reader.png`: approved reading concept.
- `inline-plan-reading-adjusting.png`: approved collapsed/expanded comparison.
- Matching `.prompt.txt` files retain the image-generation specifications.
- `deployed-desktop-open.png`: actual deployed UI with one adjustment expanded.
- `deployed-mobile-closed.png`: actual deployed UI with all adjustments collapsed.

The implementation uses locally hosted Inter, a 726px desktop text column, restrained indigo disclosure links, and Tailwind-styled Radix controls. Screenshots were captured from the public tainer deployment without changing stored values.
